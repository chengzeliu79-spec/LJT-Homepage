# LJT-Homepage

Personal academic homepage of **Junteng Liu**, a Ph.D. candidate at the HKUST NLP Group working on natural language processing and machine learning.

The site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll theme and is served with GitHub Pages at
<https://chengzeliu79-spec.github.io/LJT-Homepage/>.

## Site content

* **About** — `_pages/about.md`: personal details, academic background, research experience, research interests, publications, skills, awards and contact information.
* **Publications** — `_pages/publications.html` together with the entries in `_publications/`: the full publication list.
* **CV** — `_pages/cv.md`: education, research experience, research interests, skills, publications, awards and contact information.

## Configuration

* `_config.yml` — site-wide settings (title, author profile, links, publication categories).
* `_data/navigation.yml` — the links shown in the top navigation bar.

Each publication is a Markdown file in `_publications/` with structured front matter (title, authors/venue, date, links and citation).
